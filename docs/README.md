# Revolit — документация платформы

Дорожная карта и справочник по устройству системы. Пишется для трёх читателей:
для владельца продукта, для разработчика (в том числе ИИ-помощника) и для тех,
кто подключится к проекту позже.

**Правило: решения фиксируются здесь.** Если о чём-то договорились в переписке,
но не записали в документацию — считайте, что не договорились.

## Состояние на 17 августа 2026

**Готово:** каркас программы, вход с двухфакторной аутентификацией, роли и права,
управление сотрудниками, журнал действий.

**В работе:** разделение на ядро и модули.

**Дальше:** механизм сущностей, контрагенты, установщик.

Подробности — в [дорожной карте](07-roadmap.md).

## Как пользоваться

- Начинать чтение с [концепции](01-concept.md) и [архитектуры](02-architecture.md).
- Перед началом работы над задачей — сверяться с [дорожной картой](07-roadmap.md).
- Приняли новое решение — дописать в [журнал решений](08-decisions.md) вместе с обоснованием.
- Меняете подход к разработке — отразить в [соглашениях](09-conventions.md).
